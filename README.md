# O Sebo Cultural — site

Site estático (HTML, CSS e JS puros) do O Sebo Cultural, João Pessoa (PB).

- Sem etapa de build: a Vercel publica a pasta raiz como está.
- `vercel.json` define o cache (antes feito pelo `.htaccess`). A compressão a Vercel faz sozinha.
- Para testar localmente: `python3 -m http.server 5173` e abra http://localhost:5173
